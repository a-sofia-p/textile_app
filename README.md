# A Global Map View of Textile Waste 
  Inspiration for this project can be found around 8,000km (50,000 miles) from New York City. In between the dry sands of the chilean Aatacam desert in Chile, the **"Cemetery of Clothes"** is a colorful man-made dumping ground of worn clothing, textiles, and accesories.   

Leveraging data form the International Trade Center (2015 - 2024), this project visualizes global worn clothing exports and the network between major exporters and their destinations.

* The map shows worn clothing exports flows by country and year.  
* The data comes from public trade statistics and is simplified for visualization.
